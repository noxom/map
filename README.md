# map

Static site on GitHub Pages with a map of visited places.

## Pages

- **[Places map](https://noxom.github.io/map/)** (`index.html`) - pins of visited cities and landmarks with a legend grouped by country.
- **[Countries map](https://noxom.github.io/map/countries.html)** (`countries.html`) - highlighted countries visited, with a legend.

On both pages, hovering over a legend item highlights the corresponding object on the map, and vice versa.

## Stack

- **Hosting:** GitHub Pages (static, no backend)
- **Maps:** [Leaflet.js](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/) tiles (vendored locally)
- **Country flags:** [flag-icons](https://github.com/lipis/flag-icons) (vendored locally)
- **Country borders:** GeoJSON from [datasets/geo-countries](https://github.com/datasets/geo-countries)
- **Data:** ES modules generated by a script from an offline GeoNames dump

## Adding places manually

**Cities** — add to `scripts/input/cities.csv`:
```
name,geonameid,photo
Hiroshima,,hiroshima.jpg
Tokyo,,
```

**Landmarks, islands, temples** — add to `scripts/input/extra-places.csv`:
```
name,country,lat,lng,photo
Angkor Wat,KH,13.4124693,103.8644054,angkor.jpg
```

Coordinates can be copied from the Google Maps URL: `@13.4124,103.8644` after the `@` sign.
Country codes are in `scripts/country-codes.csv`.
Photos go to `assets/img/` — specify only the filename in the CSV.

Then run:
```
make generate
```

To force-regenerate all records (e.g. after adding a photo to an existing city):
```
make generate-force
```

## Adding places from a photo library

Places and cities can also be collected automatically from a directory tree of photos.

**Landmarks** — create `place.csv` anywhere in the source directory:
```
name,country,lat,lng,photo
Cape of Good Hope,ZA,-34.3586894,18.457325,DSC0011.jpg
```

**Cities** — create `city.csv` anywhere in the source directory:
```
name,geonameid,photo
Almaty,,IMG_2586.JPG
```

The `photo` filename is relative to the CSV file itself.
Country codes are in `scripts/country-codes.csv`.

Then run (uses `map_px/` by default):
```
make collect
```

Or with a custom directory:
```
make collect BASE_DIR=D:/my/photos
```

The script recursively finds all `place.csv` and `city.csv` files, deduplicates entries, resizes photos to 1024px, copies them to `assets/img/`, and writes `scripts/input/mega-places.csv` and `scripts/input/mega-cities.csv`. Logs are saved to `scripts/logs/`.

After collecting, run `make generate` to rebuild the map data.

To re-process and overwrite already copied photos:
```
make collect-force
```
