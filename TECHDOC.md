# Карта посещённых мест — техническая документация

## Цель проекта
Статический сайт на GitHub Pages с двумя страницами:
1. **Карта с пинами** (`index.html`) — отмечены конкретные посещённые города/места, рядом легенда со списком мест, сгруппированных по странам.
2. **Карта мира** (`countries.html`) — закрашены страны, в которых был, рядом легенда со списком этих стран.

На обеих страницах при наведении на элемент легенды соответствующий объект на карте временно подсвечивается (и наоборот — при наведении на объект карты подсвечивается элемент легенды).

Высокая точность не требуется, проект бесплатный, без бэкенда и отдельного хостинга.

## Стек
- **Хостинг:** GitHub Pages (статика).
- **Карты:** [Leaflet.js](https://leafletjs.com/) + тайлы [OpenStreetMap](https://www.openstreetmap.org/) (бесплатно, без ключей API при умеренной нагрузке).
- **Границы стран:** GeoJSON-набор [datasets/geo-countries](https://github.com/datasets/geo-countries) (свойства `name`, `ISO3166-1-Alpha-2`, `ISO3166-1-Alpha-3`), лежит статически в `data/world-countries.geojson`.
- **Данные о местах/странах:** генерируются скриптом в виде ES-модулей (`assets/js/places-data.js`, `assets/js/countries-data.js`) — без БД и без отдельного запроса JSON по сети.
- **Шаблонизация:** чистый HTML/CSS/JS (ES-модули), без сборщика — GitHub Pages раздаёт файлы как есть.

## Генерация данных по списку городов

### Источник данных
**GeoNames** (geonames.org) — открытая международная база городов. У каждого города есть уникальный `geonameid`, координаты, название и **ISO 3166-1 alpha-2 код страны**, что совпадает с кодами в GeoJSON границ.
- Дамп `cities15000.txt` скачан один раз в `scripts/data/` — скрипт работает офлайн, без обращения к внешним API при каждом запуске.

### Входной файл
`scripts/input/cities.txt` — простой текстовый список городов, один на строку (строки с `#` игнорируются):
```
Yakutsk
Moscow
Limassol
Istanbul
```

### Запуск
```
make generate
```
(эквивалент `python3 scripts/generate_data.py`)

### Алгоритм (`scripts/generate_data.py`)
1. Загрузить дамп GeoNames в индекс по полям `name`/`asciiname`/`alternatenames` (в нижнем регистре).
2. Для каждого города из входного списка найти запись:
   - точное совпадение по имени (включая альтернативные названия на разных языках);
   - при нескольких совпадениях — выбрать запись с наибольшим `population`;
   - если совпадений нет — предупреждение в консоль, город пропускается (добавляется вручную).
3. Извлечь `name`, `latitude`, `longitude`, `country code`, `geonameid`; не дублировать уже добавленные `geonameid`.
4. Записать результат как ES-модуль `assets/js/places-data.js`:
   ```js
   export const places = [
     { "name": "Yakutsk", "country": "RU", "lat": 62.03114, "lng": 129.72288, "geonameid": 2013159 },
     ...
   ];
   ```
5. Собрать уникальные коды стран и записать `assets/js/countries-data.js`:
   ```js
   export const visitedCountries = ["CY", "RU", "TR"];
   ```

> Скрипт покрывает только **города**. Возможность добавлять произвольные точки (например, достопримечательности, не привязанные к городу из GeoNames) — задел на будущее: такие точки можно дописывать вручную прямо в `places.json`-подобную структуру (без `geonameid`), и это не будет конфликтовать с автогенерацией, так как скрипт не трогает записи с уже известными `geonameid` повторно.

## Как карты получают данные
Поскольку открытие `index.html`/`countries.html` напрямую с диска (`file://`) блокирует `fetch` JSON по CORS, данные о местах и странах не запрашиваются по сети, а импортируются как ES-модули прямо в JS карт:

```js
// pins-map.js
import { places } from './places-data.js';

// countries-map.js
import { visitedCountries } from './countries-data.js';
```
HTML не меняется при перегенерации данных — достаточно перезаписать `*-data.js` через `make generate`.

GeoJSON границ стран (`world-countries.geojson`) — большой статический файл, его по-прежнему загружают через `fetch` (требует раздачи через http-сервер, что и обеспечивает GitHub Pages).

## Отрисовка карты пинов (`pins-map.js`)
- Создаёт карту Leaflet с тайлами OSM, ставит маркер на каждое место из `places`.
- Строит легенду `#legend-list`: места группируются по странам (название страны — через `Intl.DisplayNames(['ru'], { type: 'region' })`), внутри — отсортированный список городов.
- При наведении на пин или на пункт легенды вызывается `setActive(id)`:
  - на DOM-элемент маркера (`marker._icon`) добавляется/убирается класс `pin-highlight`, который через CSS `filter: hue-rotate(...) saturate(...)` временно меняет **только цвет** пина (форма и размер не меняются);
  - соответствующий пункт легенды получает/теряет класс `active`.

## Отрисовка карты стран (`countries-map.js`)
- Загружает `world-countries.geojson`, красит страны через `style` callback: посещённые (код входит в `visitedCountries`) — зелёным, остальные — серым.
- Строит легенду `#legend-list` из фич GeoJSON, отфильтрованных по `visitedCountries`, отсортированных по названию.
- При наведении на страну на карте или на пункт легенды вызывается `setActive(code)`:
  - стиль слоя страны временно меняется на `HIGHLIGHT_STYLE` (другой цвет заливки/обводки), при уходе курсора — `geoLayer.resetStyle(...)` возвращает исходный стиль;
  - соответствующий пункт легенды получает/теряет класс `active`.

> Известный нюанс: полигон России пересекает antimeridian (180° долготы), из-за чего Leaflet может отрисовывать часть страны "с другой стороны" карты. Корректное решение — предварительно разрезать такие полигоны в GeoJSON по 180° меридиану (отдельная задача, пока не реализована).

## Стили и легенда (`assets/css/style.css`)
- `.page` — флекс-разметка «карта + боковая панель легенды» (`#legend`, фиксированная ширина, скролл).
- `#legend li.country` — заголовок страны (жирный, без подсветки при наведении), `ul.cities` — вложенный список городов.
- `#legend li:hover`, `#legend li.active` — подсветка пункта легенды (жёлтый фон).
- `.pin-highlight` — класс, временно применяемый к DOM-маркеру пина для смены цвета через CSS-фильтр.

## Деплой на GitHub Pages
1. В настройках репозитория: **Settings → Pages → Source** — выбрать ветку `main` и папку `/ (root)`.
2. Файлы лежат статически (без шага сборки), Leaflet подключается через CDN (`unpkg`).
3. `world-countries.geojson` уже лежит в репозитории — внешние запросы не требуются.

## Добавление новых мест/стран
1. Добавить название города в `scripts/input/cities.txt` (по одному на строку).
2. Выполнить `make generate` — скрипт допишет новые места в `places-data.js` и пересоберёт список стран в `countries-data.js`.
3. Если города нет в базе GeoNames — скрипт выведет предупреждение; такое место можно дописать вручную прямо в `places-data.js` (без `geonameid`).
